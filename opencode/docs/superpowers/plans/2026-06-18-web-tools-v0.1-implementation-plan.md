# Web Tools v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the `web-tools` plugin bundle to opencode with `web_search`, `fetch_content`, and `maps_search`, plus config, budgets, install wiring, and docs.

**Architecture:** Implement one TypeScript plugin entrypoint at `plugins/web-tools.ts` that registers three lean custom tools and delegates provider, cache, pricing, DB, and config work to focused helper modules under `plugins/web-tools/`. Keep install/uninstall integration explicit: add one fleet component, one package-fragment merge path, one runtime config file, and targeted tests that pin behavior at the plugin, installer, and docs-manifest layers.

**Tech Stack:** OpenCode plugin API (`@opencode-ai/plugin`), Bun, TypeScript modules loaded directly by OpenCode, SQLite (`bun:sqlite` or current repo-standard runtime DB access), YAML config, shell installer scripts, Bun tests in `scripts/tests/`.

**Working Directory Convention:** Run the commands below from `opencode/` unless a step explicitly says otherwise. The one repo-root file in scope is `../README.md`.

```ts
export function estimateGeminiCall(input: {
  model: string;
  inputTokens: number;
  outputTokens: number;
  tool: "google_search" | "googleMaps" | "url_context";
}) {
  const modelPrice = prices[input.model];
  const tokenCost = input.inputTokens * modelPrice.input_cost_per_token + input.outputTokens * modelPrice.output_cost_per_token;
  const toolFee = feeTable[input.model]?.[input.tool] ?? 0;
  return roundUsd(tokenCost + toolFee);
}
```

```ts
export async function executeWebSearchTool(args: WebSearchArgs, runtime: WebToolsRuntime) {
  const request = normalizeWebSearchArgs(args, runtime.config.webSearch);
  const cacheKey = hashWebSearchRequest(request);
  const cached = runtime.cache.getWebSearch(cacheKey);
  if (cached) return cached;

  const result = await runtime.providers.searchWithFallback(request);
  const publicResult = { results: result.results.map(toPublicSearchResult) };
  runtime.cache.setWebSearch(cacheKey, publicResult);
  void runtime.db.recordWebSearch(request, result);
  void runtime.usage.recordFromSearch(result.metadata);
  return publicResult;
}
```

```ts
export async function executeFetchContentTool(args: FetchContentArgs, runtime: WebToolsRuntime) {
  const request = normalizeFetchContentArgs(args, runtime.config.fetchContent);
  const cacheKey = hashFetchContentRequest(request);
  const cached = runtime.cache.getFetchContent(cacheKey);
  if (cached) return cached;

  const result = await runtime.providers.fetchWithFallback(request);
  const publicResult = {
    results: result.results.map((item) => request.mode === "map" ? { url: item.url, title: item.title } : { url: item.url, title: item.title, content: item.content }),
  };

  runtime.cache.setFetchContent(cacheKey, publicResult);
  void runtime.db.recordFetchContent(request, result);
  void runtime.usage.recordFromFetch(result.metadata);
  return publicResult;
}
```
